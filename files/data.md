# 📍 이쯤 — 샘플 데이터 (재검증판)

`data.js`에 있는 16개 식당 샘플 데이터 설명 문서예요.

> ⚠️ 이전 버전 데이터는 지도 장소검색(구글 플레이스) 결과만으로 만들어서 실제와 다른 부분이 있었어요.
> 이번 버전은 **네이버 블로그·식신 등 실제 방문 후기 콘텐츠**로 장소명·특징을 먼저 확인하고,
> 그 다음 지도 데이터로 좌표·전화번호·영업시간을 교차 확인해서 다시 만들었어요.
> 그래도 `phone: null`이거나 "영업시간 매장 확인 필요"라고 되어 있는 항목은 정보가 불명확했던 곳이니,
> 시연 전에 한 번 더 확인하는 걸 추천해요.

## 데이터 구성

| 그룹 | 지역 | 개수 | id 범위 |
|---|---|---|---|
| 한 지역 검색용 | 을지로3가 | 8곳 | 1~8 |
| 중간지점 검색용 (화곡 ↔ 성수) | 공덕역 인근 | 8곳 | 9~16 |

## 스키마

```ts
{
  id: number,
  name: string,
  region: string,           // "을지로3가" | "공덕"
  address: string,
  lat: number,
  lng: number,
  moodTags: string[],       // 분위기 태그
  cuisineType: string,      // "한식" | "양식" | "일식" | "중식"
  menuTags: string[],
  recommendedRound: string[], // "1차" | "2차" | "3차 이상"
  rating: number,
  reviewSummary: string,
  phone: string | null,
  reserveUrl: string | null,
  menu: string[],
  hours: string
}
```

## 태그 풀

- **분위기 태그**: `조용한` / `시끌벅적` / `단체석` / `회식` / `데이트` / `혼술` / `루프탑` / `감성`
- **음식 종류**: `한식` / `양식` / `일식` / `중식`
- **차수 태그**: `1차`(식사류) / `2차`(술집·포차) / `3차 이상`(카페·바, 조용한 곳)
- 모든 선택 옵션(컨셉·차수·분위기·음식 종류)에는 `모르겠어요`(필터 없이 전체 노출) 항목도 포함돼요.
